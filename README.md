## Profile

I build focused desktop software and Linux systems, from a native macOS terminal to cross-platform media tools and handheld hardware. I care about measurable performance, direct interfaces, privacy-conscious architecture, and software people can inspect and own.

## Public projects

### [Termatica](https://github.com/sebastianmiletic/termatica)

A native macOS terminal written in Objective-C, AppKit, Metal, and C. The universal app is under 2 MB and includes real PTYs, tabs, arbitrary splits, SSH profiles, terminal graphics, automation, and reproducible performance benchmarks.

`Objective-C` `AppKit` `Metal` `C` `macOS`

[Source](https://github.com/sebastianmiletic/termatica) · [Latest release](https://github.com/sebastianmiletic/termatica/releases/latest) · [Benchmarks](https://github.com/sebastianmiletic/termatica/blob/main/docs/BENCHMARKS.md)

### [Open Cloud](https://github.com/sebastianmiletic/opencloud)

A cross-platform desktop streaming tracker for macOS, Windows, and Linux. It combines TMDB and OMDB data, an inline player, Supabase authentication and sync, collections, watch progress, and a native ad and popup blocker in a Tauri shell.

`Tauri` `Rust` `JavaScript` `Supabase` `macOS · Windows · Linux`

[Source](https://github.com/sebastianmiletic/opencloud) · [Latest release](https://github.com/sebastianmiletic/opencloud/releases/latest)

### [Sparkdeck](https://github.com/sebastianmiletic/sparkdeck)

An open-source, pocket-sized cyberdeck project designed for Arch Linux, emulation, coding, radio signal decoding, and portable security work.

`QML` `Arch Linux` `Cyberdeck`

[Source](https://github.com/sebastianmiletic/sparkdeck)

### [Hyprland dotfiles](https://github.com/sebastianmiletic/hyprland-dotfiles)

My Arch Linux desktop configuration built around Hyprland and Quickshell. It includes custom keybindings, desktop widgets, Google Tasks integration, contextual Gemini actions, terminal tooling, and delayed lid-suspend behavior.

`Hyprland` `Quickshell` `QML` `Lua` `Shell`

[Source](https://github.com/sebastianmiletic/hyprland-dotfiles)

## Technical focus

- **Native desktop:** Objective-C, AppKit, Metal, Rust, Tauri
- **Terminal systems:** PTYs, escape-sequence parsing, SSH, splits, automation, benchmarking
- **Application development:** JavaScript, HTML/CSS, Supabase, authentication, sync, desktop packaging
- **Linux environments:** Arch Linux, Hyprland, Quickshell, QML, Lua, shell configuration
- **Product values:** compact binaries, clear interfaces, reproducible claims, user-owned configuration

## Current direction

I am continuing to improve Termatica, build cross-platform desktop applications, and experiment with Linux interfaces that work across full desktops and compact hardware.
