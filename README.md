## Repositories

- **[Termatica](https://github.com/sebastianmiletic/termatica)**: an under-2 MB native macOS terminal with PTYs, SSH, splits, AppKit and Metal rendering, and reproducible benchmarks.
- **[Open Cloud](https://github.com/sebastianmiletic/opencloud)**: a Tauri streaming tracker for macOS, Windows, and Linux with Supabase sync and native blocking controls.
- **[Sparkdeck](https://github.com/sebastianmiletic/sparkdeck)**: a pocket-sized Arch Linux cyberdeck for coding, emulation, radio work, and security tools.
- **[Hyprland dotfiles](https://github.com/sebastianmiletic/hyprland-dotfiles)**: my Hyprland and Quickshell desktop configuration, widgets, integrations, and terminal workflow.
