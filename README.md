## Projects

- [Termatica](https://github.com/sebastianmiletic/termatica) — an under-2 MB native macOS terminal with SSH, tabs, splits, AI/TUI compatibility, AppKit, and optional Metal rendering.
- [OpenCloud](https://github.com/sebastianmiletic/opencloud) — a cross-platform streaming tracker with playback, Supabase accounts, and privacy-focused progress sync.
- [OnePlus 6T Hyprland rice](https://github.com/sebastianmiletic/oneplus6t-hyprland-rice) — a Hyprland configuration project for the OnePlus 6T.

## Current direction

I build compact software that keeps the interface close to the work: terminal-native controls, native desktop performance, keyboard and mouse parity, and reproducible verification.
